# 简报 TASK-001：《狼来了》—— 一部可以直接上线播放的动画短片

## 任务

用户原话：「制作一个精美的、极其精美、简直可以上线播放的Flash动画。当然也可以不是Flash了，而是现在更好的这种制作工具。然后主题就是狼来了的故事。」

我的理解：做一部**有完整叙事、有导演感、有美术风格**的动画短片，题材是伊索寓言《狼来了》（牧羊少年与狼）。不是「狼来了」这句成语的小图标 / 十几秒小 demo，而是**一部可以当展映素材、片头、发布会开场播放的成片**。

「Flash」指的是那种「打开就能播、有镜头语言、有美术风格」的**观感**，不是 .swf 技术格式。实现媒介你定，但成品必须满足下面「验收」的全部硬指标。

## 验收（每条都能用一条命令或一个明确步骤判定真假）

1. **构建与测试**：`npm ci && npm run build && npm test` 退出码全为 0。测试数量从真实 stdout 解析，不许手抄。
2. **零外部请求**：生产构建产物打开后，**外部网络请求数 = 0**（无 CDN、无外链字体、无外链图片/音频），`console error = 0`，`pageerror = 0`。
3. **成片可导出**：用 Playwright 逐帧确定性渲染 + ffmpeg 导出 **H.264 / yuv420p / ≥1280×720 / 30fps** 的 MP4，**音频轨存在**（AAC），成片时长与片长一致（误差 ≤ 1 帧）。
4. **叙事完整**：一条**单镜到底的完整时间线**（片长由你定，建议 100–180 秒），能从头播到尾，结尾有明确的「寓意」落幅。仓库里要有分镜表 `docs/storyboard.md`（镜号 / 时长 / 画面 / 台词 / 音效 / 转场），逐镜可对照。
5. **动画流畅**：动画只允许在 `transform` / `opacity` 上做动画属性（禁止动画 `width/height/top/left`）；60 帧采样 frameId **互不相同**、时间戳**严格递增**。
6. **可访问性与响应式**：仅用键盘可完成 播放 / 暂停 / 重播 / 字幕开关；焦点环可见；375px 与 1440px 下**无横向滚动、无元素重叠**；`prefers-reduced-motion` 有降级路径。
7. **设计质量线**：`handoff/spec/design-quality-bar.md` 的 A–E 逐条有结论，**G 禁项 = 0**；正文文字对比度 **≥ 4.5:1**（用工具量，不许靠肉眼）。
8. **可离线分发**：构建产物资源全部本地化；**另产出一份单文件 HTML**（JS/CSS/资源全部内联），用 `file://` 打开时 `console error = 0`、外部请求 = 0。

## 故事事实（已核实，公共领域，供你写分镜）

伊索寓言《牧羊少年与狼》。**必须保留的结构**（你可以重新设计每一场的美术与镜头，但不能丢掉这三声呼喊与最后的后果）：

1. **设定**：少年独自在山上放羊，山坡下有一座村庄。
2. **第一声**：羊群突然安静，少年看见远处有狼的影子（其实并非真狼），他大喊「狼来了！狼来了！」。村民气喘吁吁爬上山，坡上什么也没有。少年笑了 —— 这是**第一次失信**。
3. **第二声**：他又喊了一次。村民又白跑一趟，比上次更生气、更不信他 —— 这是**信任被消耗**。
4. **第三声**：这一次狼真的来了，扑向羊群。少年拼命喊「狼来了！」，村民听见了，**却没有上山** —— 因为他们认定他又在骗人。羊被叼走。
5. **寓意**：一次谎言足以让人不再相信你，哪怕你说的是真话。

汉语语境补充：「狼来了」是汉语常用成语，比喻用虚言恐吓、最后一次失信 —— 可作为片尾落幅的概念锚点。

**你必须自己完成的创作**（不要照抄任何现成改编）：分镜节奏、美术风格、镜头语言、角色造型、色彩与光影、字幕与台词、声音设计与配乐。
