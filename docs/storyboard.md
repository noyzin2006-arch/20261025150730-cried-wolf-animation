## 声音设计总表

- 采样率 48000Hz、单声道 16bit PCM；全片 150.000 秒。
- 音乐：4/4 拍、80 BPM，每拍 0.75 秒，每小节 3 秒，50 小节。
- 调式：D natural minor；主题动机 D4–F4–A4（293.66 / 349.23 / 440 Hz）。
- 和声进行：0–100s：Dm / Bb / Gm / A；100–141s：Dm / Eb / Dm / A；141–150s：Dm。
- 119.5–123.5 秒为强制静默窗口（PCM 逐点为 0），第三次呼喊消失在空谷里。
- 全部 53 个声音事件由 `scripts/generate-audio.mjs` 一次性离线合成，浏览器播放与 MP4 导出使用同一段 WAV，不重复实时混音。
